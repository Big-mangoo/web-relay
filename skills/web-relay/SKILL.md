# Web Relay (网页端问答接力技能)

本技能用于在**不依赖任何不稳定逆向 API、不承担任何封号与风控风险**的前提下，让本地智能体借用网页端顶级大模型（尤其是网页端可用的超长上下文与推理算力）完成本地工程、代码重构、算法实现与复杂长文分析。

---

## 核心机制：人在回路双向接力（Relay Loop）

```
[用户指令: "用网页接力，执行XXX"]
        │
        ▼
[本地 Agent] ─── 自动扫描上下文/目标代码
        │        组装严格 XML 补丁契约 (CONTRACT)
        │        运行 gemini_relay.py pack 写入系统剪贴板
        ▼
[控制台提示] ─── "🏓 发球完成！提示词已复制到剪贴板，请到网页端 Ctrl+V 发送并复制回复。"
        │
        ▼ (用户在官方网页端 Ctrl+V 发送，享受原生超长上下文与顶尖算力)
[网页端大模型]
        │
        ▼ (用户点击网页端回复底部的"复制全部回复")
[用户指令: "已复制" 或 直接粘贴网页回复]
        │
        ▼
[本地 Agent] ─── 自动解析 <file>, <exec>, <status>, <summary>
        │        安全门禁审计（路径穿越拦截、高危命令拦截）
        │        自动原子修改本地文件并运行 <exec> 验证命令
        │
        ├── [命令报错 / 未完成] ──> 自动捕获报错堆栈，重写下一轮提示词至剪贴板
        │                           提示用户继续切回网页端 Ctrl+V（循环直到调通）
        │
        └── [验证通过且 done]   ──> 🎉 宣布任务圆满完成！
```

## 执行规程（Agent 必读与执行步骤）

> **脚本定位**：以本 `SKILL.md` 所在目录为基准拼接 `scripts/gemini_relay.py`，项目目录一律通过 `--root` 指定。不要假定当前工作目录就是技能目录，也不要写死个人绝对路径。

当用户发出包含 **“用网页接力”、“网页接力执行”、“网页接力分析”** 或 **`/web-relay`** 的指令时，本地 Agent 必须按以下步骤推进：

### 阶段一：发球（Outbound - 打包与提示词生成）

1. **自主扫描与定位上下文**：
   - 根据用户的任务目标，主动使用 `Glob` 与 `Grep` 定位项目中涉及的目标代码文件、配置文件或报错日志；
   - 估算文件总体积（通常控制在 50~100 个文件以内，单文件 ≤100KB），无需用户手动一条条告知文件路径。

2. **调用接力引擎或生成提示词**：
   - **方式 A（优先推荐，自动打入剪贴板并归档）**：
     ```powershell
     python "<技能目录>/scripts/gemini_relay.py" pack --root <项目目录> -f <目标文件列表> -p "<详细任务要求>"
     ```
     提示词会同时写入系统剪贴板与 `<项目目录>/.web-relay/<项目名>/rNNN-out-<时间戳>.md`，
     剪贴板失效时可从归档文件手动取回。
   - **方式 B（兜底与回显）**：
     若用户环境剪贴板不便，本地 Agent 同时向用户输出清晰的提示词摘要与关键文件清单，并将完整 Prompt 保存在临时文件或在代码块中给出。

3. **给用户的发球通报**：
   发球后，向用户输出一段精炼的指引：
   - 告知已打包的文件清单与任务目标；
   - 提示词已存入系统剪贴板；
   - **指引一句话**：“请切换到你在用的网页端大模型，直接按 `Ctrl+V` 发送；等生成完毕后，点击该条回复底部的‘复制全部回复’图标，切回这里直接发送‘已复制’或把内容贴在输入框即可！”

---

### 阶段二：接球（Inbound - 解析、落盘与本地验证）

当用户回复“**已复制**”、“**贴上网页端回复文本**”或直接发送网页版答案时，Agent 必须立即接球：

1. **提取与解析结构化标签**：
   - 若用户回复“已复制”，Agent 执行：
     ```powershell
     python "<技能目录>/scripts/gemini_relay.py" catch --root <项目目录> --once
     ```
     接力引擎会先做剪贴板回显校验（防止把发球提示词当成回复），然后把回复原文归档为
     `rNNN-in-<时间戳>.md`，再解析 `<file path="...">` 落盘、覆写前自动备份，
     最后执行 `<exec>` 验证命令。**不要加 `-y`**：落盘前的人工确认是 diff 审查的唯一关口。
   - 若用户直接将文本贴在对话框中，Agent 自行解析：
     - `<file path="相对路径">完整代码</file>`：使用 `Write` 或 `Edit` 工具写入目标文件。
     - `<exec>命令</exec>`：使用本地 shell 执行测试验证命令（如 `python xxx.py`、`npm test`）。
     - `<status>done | continue</status>`：判断任务是否完成。
     - `<summary>说明</summary>`：变更概述。

2. **安全门禁检查**：
   - 严禁执行模型返回的绝对路径修改（如 `C:\Windows\...`）或越界相对路径（`../../...`）。
   - 严禁执行破坏性系统命令（如 `rm -rf`、`del /f /s /q`、`format` 等）。

---

### 阶段三：回环判定（Relay Loop - 续球或完工）

1. **分支 A：成功且已完成（`status == done` 且测试全过）**：
   - 向用户汇报本次修改落盘的文件清单、行数变更与本地命令运行成功的输出证据；
   - 宣布接力任务圆满完成。

2. **分支 B：失败或任务未完成（测试报错 或 `status == continue`）**：
   - Agent 自动截取报错输出（stderr、Traceback、失败的断言信息）；
   - 如果使用接力脚本，脚本在 `catch` 遇到失败时会**自动生成下一轮续球提示词并打入剪贴板**；
   - Agent 明确提示用户：“⚠️ 本地运行测试命令报错如下：`[错误简述]`。下一轮诊断修复提示词已自动存入剪贴板！请切回网页端直接 `Ctrl+V` 继续，直到彻底调通。”

## 契约格式（Prompt Contract 规范说明）

发球给网页端大模型时，提示词首尾必须强制约束以下 XML 标签（内置接力脚本已自带加固）：

```xml
【不可违背的代码与操作输出契约】
你必须且仅能通过以下 XML 标签输出你的分析结果、代码变更与本地命令：

1. 文件改写与新建（必须使用完整文件内容，严禁使用代码围栏 ```，严禁省略无关代码）：
<file path="path/to/file.ext">
完整的文件代码或内容
</file>

2. 本地建议执行的验证命令（如运行测试、安装包）：
<exec>python -m pytest tests/test_calc.py</exec>

3. 任务状态（仅限 done 或 continue）：
<status>done</status>

4. 一句话变更摘要：
<summary>修复了浮点数相加丢失精度的问题并补充了单测</summary>
```
